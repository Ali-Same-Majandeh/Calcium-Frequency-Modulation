# 1. Introduction


The **Model.ipynb** notebook provides an adapted version of the [main branch](https://github.com/Ali-Same-Majandeh/Calcium-Frequency-Modulation) to study the effects of ELF-PEMF on ROS production. Running this code is identical to the main branch, with the exception of three newly added parameters to the model: T_period, B_max, and duty_cycle.
